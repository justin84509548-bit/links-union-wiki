# Wiki content workspace

Copy `_template.md` into the appropriate group folder. Markdown files are working source material for the Wiki; they are not automatically treated as verified claims.

Allowed `group` values: `academic`, `hp`, `business`, `art`, `shared`.

Allowed `status` values:

- `collecting`: evidence is still being gathered.
- `draft`: a group is writing and checking the content.
- `review`: ready for teacher review.
- `approved`: teacher review is complete.

`publish: true` is accepted only when `status: approved`, `reviewer` and `approval_date` are all present. Justin still performs the final layout and integration check before merging.
